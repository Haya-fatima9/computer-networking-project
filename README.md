# Computer Networking Project

## About the Project
This project was created using Cisco Packet Tracer to practice computer networking concepts and network configuration.

## Tools Used
- Cisco Packet Tracer

## Project File
The `.pkt` file contains the network project and can be opened using Cisco Packet Tracer.

## How to Run
1. Download the `.pkt` file from this repository.
2. Open Cisco Packet Tracer.
3. Open the downloaded project file.
